## Neues Rezept hinzufügen

Direkt auf GitHub, ohne Skript:

1. **Neue Datei** anlegen: oben rechts auf **Add file → Create new file**
2. Dateiname: `<name>.md`, z. B. `tiramisu.md` – Inhalt siehe `TEMPLATE.md` kopieren und ausfüllen
3. **Bild hinzufügen**: in derselben Datei-Ansicht auf **Add file → Upload files** gehen und das Foto nach `images/` ziehen, Dateiname passend zum Rezept, z. B. `images/tiramisu.jpg`
4. Im Rezept das Bild einbetten:

   ```markdown
   # Tiramisu

   ![Tiramisu](images/tiramisu.jpg)
   ```
5. **Commit** – fertig. GitHub rendert das Bild automatisch in der Rezeptseite und in der Vorschau.
